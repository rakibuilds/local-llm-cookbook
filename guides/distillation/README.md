# Model Distillation

Learn how to transfer useful capabilities from larger language models (teacher models) into smaller, more efficient models (student models).

This guide covers the fundamentals, teacher selection, dataset generation, student training, and evaluation of distilled language models.

## What Is Model Distillation?

Model distillation is a machine learning technique in which a smaller **student model** learns to reproduce useful behavior or knowledge from a larger **teacher model**.

The objective is to create a more efficient model that can perform selected tasks with lower computational and memory requirements.

A distilled model may be easier to run locally, deploy on limited hardware, or integrate into applications.

Distillation does not guarantee that the student will match the teacher's overall capabilities. Results depend on the teacher, dataset, training method, student architecture, and evaluation process.

## Distillation Methods

This cookbook will explore several approaches:

- **Response-based distillation:** Train the student using outputs generated by the teacher.
- **Logit-based distillation:** Train the student using the teacher's probability distributions over possible tokens.
- **Feature-based distillation:** Transfer selected internal representations from the teacher.
- **Relation-based distillation:** Teach the student relationships between representations or examples.

Not every method works with every model architecture or training framework. Some methods require access to teacher logits or internal model representations.

## Requirements

Requirements depend on the selected models and distillation method.

Common tools include:

- Python
- PyTorch
- Hugging Face Transformers
- Hugging Face Datasets
- PEFT
- Ollama (for supported local teacher-model workflows)

A GPU is helpful for training, but some data-generation and smaller-model experiments can run on a CPU. Hardware requirements must be evaluated for the specific model, sequence length, batch size, precision, and training method.

## Important Concepts

- **Teacher model:** The model that provides knowledge, outputs, or training signals.
- **Student model:** The smaller model being trained.
- **Distillation dataset:** Examples used to teach the student.
- **Soft targets:** Probability distributions produced by a teacher model.
- **Temperature:** A parameter that controls the smoothness of probability distributions during certain distillation methods.
- **Evaluation:** Measuring whether the student retains the capabilities required for its intended use.

## Distillation vs. Other Techniques

| Technique | Main purpose |
|---|---|
| Distillation | Transfer knowledge or behavior from a teacher to a student. |
| Fine-tuning | Adapt a pretrained model to a task or dataset. |
| LoRA | Fine-tune selected model parameters through low-rank adapters. |
| Quantization | Reduce model weight or computation precision to improve efficiency. |
| Pruning | Remove selected model parameters or structures. |

These techniques can be combined. For example, a student model can be distilled, fine-tuned with LoRA, and then quantized for local deployment.

## Design Principles

This cookbook follows these principles:

1. Prefer local-first workflows and openly available tools.
2. Explain hardware requirements realistically.
3. Keep teacher-generated data reproducible and inspectable.
4. Document model and dataset licenses.
5. Evaluate quality rather than assuming a smaller model is equivalent to its teacher.
6. Separate data generation, training, and evaluation into understandable steps.
